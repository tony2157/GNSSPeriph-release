==========================================================
 Building the Here4 (Blue) AP_Periph firmware
==========================================================

ONE-TIME SETUP
--------------
Get the submodules (only needed on a fresh clone):
       git submodule update --init --recursive

That's it. The ardupilot submodule points at tony2157/my-ardupilot
(branch here4-hpposecef) and already includes both the HPPOSECEF
changes and the CubeID firmware blob (ardupilot/ROMFS_custom/
CubeID_fw.bin), so no manual file placement is needed.


BUILD
-----
Run from this root folder:

    ./waf configure --board Here4
    ./waf AP_Periph

Takes ~30 s (a few seconds on rebuilds). With Python 3.12 or newer
the ./waf wrapper adds scripts/py3_compat to PYTHONPATH, because the
vendored waf still imports the removed imp and pipes modules.

To build a different board in the same build/ folder, run
./waf clean after configure, or the MAVLink headers are not generated.


WHERE THE FIRMWARE ENDS UP
--------------------------
    build/Here4/bin/AP_Periph.apj            <- flash this in Mission Planner (DroneCAN)
    build/Here4/bin/AP_Periph_with_bl.hex    <- full image incl. bootloader (SWD/DFU)
    build/Here4/bin/AP_Periph.bin
    build/Here4/bin/AP_Periph.elf            <- for debugging


AFTER FLASHING (CubeID check)
-----------------------------
Watch the DroneCAN console for:
    CubeID fw v1.12.0 size 164902 crc 0x257cd554
and, once the module has updated or was already current:
    CubeID running fw v1.12.0
That confirms the embedded CubeID blob was found and sent to the
CubeID node. (Param CUBEID_FW_UPDATE = 1 enables this; default on.)


NOTES
-----
- This build also includes the DroneCAN HpposEcef telemetry feature
  (ardupilot.gnss.HpposEcef, id 20008).
- The HPPOSECEF parsing, DSDL and CubeID blob live in the ardupilot
  submodule (tony2157/my-ardupilot, branch here4-hpposecef); the
  DroneCAN publisher is in AP_Periph/sensor_gps.cpp here.
- The vehicle only logs HpposEcef (ECEF log message) if its firmware
  has the matching AP_GPS_DroneCAN subscriber and the same DSDL file.
- The CubeID_fw.bin is committed (force-added; ROMFS_custom is normally
  gitignored) so the build is self-contained on a fresh clone. It is
  CubeID v1.12.0 for Here4 (FEM build), taken from the official
  GNSSPeriph v1.15.9 Here4 firmware. Do not use it for Here3+.
